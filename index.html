Security & trust

Built like financial infrastructure, because it is.

Every transaction on Nan runs through the same verification and settlement guarantees, whether it's initiated by a person or an agent.

Non-custodial by default

Funds settle directly to programmable wallets. Nan never holds user balances outside of active escrow.

Verified settlement

Every payment, agent action, and escrow release is recorded on-chain and auditable end to end.

Granular permissions

Agents operate strictly within limits you set — amount, counterparty, and time-bound expiry, always revocable.
